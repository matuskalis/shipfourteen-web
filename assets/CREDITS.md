# Texture sources

- `moon-color.webp` — LROC colour map (`lroc_color_poles_2k.tif`), resized to 2048x1024, WebP q72.
- `moon-bump.webp` — LOLA elevation model (`ldem_4.tif`), normalised to 8-bit greyscale, 1024x512, WebP q82.

Both derived from NASA's Scientific Visualization Studio CGI Moon Kit:
https://svs.gsfc.nasa.gov/4720/

NASA SVS material is in the public domain. Credit: NASA's Scientific Visualization Studio.
